## Not Enough To Mark Complete

The following are not enough:

- GitHub package exists.
- Browser page loaded.
- Form is prefilled.
- Draft copy exists.
- Public reply was posted but no official engagement occurred.
- Arc/Circle/Encode public pages are visible.
- A checklist, runbook, or status page says what to do next.

## Minimum Evidence To Mark Goal Complete

At least one of these must be directly evidenced:

- Arc official reposts, quotes, replies, or spotlights KOLMarket.
- Arc official ecosystem page lists KOLMarket.
- Arc team provides direct official confirmation that KOLMarket is accepted for ecosystem review/listing/spotlight.

And the active external submission path should have receipts:

- Encode checkpoint submitted, if using Hackathon path.
- Circle Grant proposal submitted, if using Grants path.
- Arc House/Discord/X/LinkedIn outreach receipts, if using community path.
