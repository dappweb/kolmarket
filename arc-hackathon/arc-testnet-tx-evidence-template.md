## Valid Evidence

Valid evidence includes:

- confirmed transaction hash on Arc explorer,
- successful explorer status,
- matching wallet and contract addresses,
- visible product flow matching the claimed transaction,
- timestamp aligned with the submission period.

## Invalid Evidence

Do not count these as successful tx evidence:

- wallet prompt only,
- quote only,
- simulation only,
- failed transaction,
- reverted transaction,
- HTTP 200 route check,
- UI card that is not backed by explorer evidence,
- transaction on the wrong chain,
- Robinhood/BSC transaction reused as Arc evidence.
